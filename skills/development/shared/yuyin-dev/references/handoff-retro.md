# 交接与复盘

多会话或用户要求时保存任务记录：
原目标/边界、完成与未完成、关键决定、改动文件、git 状态、
测试命令/结果/对应基线、阻塞和下一步。
区分未提交/已提交/已推送/已部署。接手核对实际状态，
代码或环境变化、验证记录不完整时才重跑相关检查，不重做已有结果。

复盘找环境改进：
找文件慢→导航；术语混淆→glossary；机械错误→lint/测试/CI；
接口版本误判→版本文档/离线快照；信息不足→脱敏日志/traceId；
检查太慢→快速/相关/CI分层；规则过多→删除重复、移按需参考。

最多 3 个高价值建议，说明证据和验证。
默认建议；用户要求落地才实施。
一次项目事实不进入通用 Skill，跨项目反复问题才升级包。
